umi4路由守卫的实现

发表于 2024-07-26 更新于 2024-07-30 分类于 react
本文字数： 1.4k 阅读时长 ≈ 1 分钟

在vue项目中实现路由守卫只需要在beforeEach中写上对应的路由守卫即可。但是在最近的一个umi4项目中没有beforeEach这个钩子，该怎么实现呢

使用wrappers配置项就能轻松实现路由守卫

使用方法

  1. 在src目录下新建wrappers文件

  2. 在路由文件中为需要守卫的路由增加wrappers配置项

  3. 在authWrap中进行权限判断

这样就实现了页面级的权限管理。虽然本项目中没有按钮级的权限需求，但是我不禁去想这个项目中该怎么实现按钮级别的权限呢？
