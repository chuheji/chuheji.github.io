css container容器查询

发表于 2024-07-30 分类于 css
本文字数： 1.7k 阅读时长 ≈ 2 分钟

前言

最近发现css新出了一项好用的响应式功能：container容器查询。这个功能是什么作用呢？我们都知道@media媒体查询匹配的是浏览器窗体，
而@container容器查询匹配的是容器，比如一个div之类的。

语法

很简单

用途

比如我们有一个容器需要适配一下，根据容器的宽度，动态的设置内容的font-size，这个貌似使用clamp结合cqw就能实现。

如果需求是宽度在500px以下加粗变色之类的需求就用得到@container了
